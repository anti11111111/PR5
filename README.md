# Практическая работа 5. Авторизация и роли

Каталог автосалона из предыдущих работ. Добавлены регистрация, вход, три роли и защита маршрутов. Данные отдаёт учебный сервер, клиент ходит к нему через Dio.

Сервер — `tool/mock-server.js`, Node.js без внешних пакетов. Порт 8081. Клиент открывается на http://127.0.0.1:5560.

```
flutter build web --no-wasm-dry-run
node tool/mock-server.js --port 8081 --origin http://127.0.0.1:5560
python tool/serve_web.py
```

Адрес API по умолчанию: `http://127.0.0.1:8081/api/`.

Учётные записи:

- `admin@salon.local` / `Admin123!` — Мирзаханян Амазасп, администратор
- `manager@salon.local` / `Manager1!` — менеджер зала
- `reader@salon.local` / `Reader12!` — читатель

Пароль на сервере хранится как scrypt-хеш. Роль берётся из подписанного токена доступа. Сборка из папки с русским именем может не записать шейдеры, поэтому для сборки удобна латинская junction-ссылка на эту папку.
